Privacy Policy

Remote Job Radar · last updated 14 November 2026

Remote Job Radar is a personal, single-user application. It runs on the owner's own computer and is operated only by that owner. This policy explains what the application does with Google user data.

Who operates this application

The application is not a service offered to the public. The only person who can run it is the person who installed it, and the only Google Account it is authorised against is that same person's account.

What data is accessed

  • Gmail, read-only (gmail.readonly): message metadata, senders, subjects and message bodies, limited to messages that appear to relate to job applications the owner submitted.
  • Google Calendar (calendar.events): the ability to create and read events on the owner's own calendar, used for interview appointments.

No other Google data is requested. The application does not request permission to send, modify or delete email.

How the data is used

  • To identify replies, rejections, assessments and interview invitations connected to the owner's job applications.
  • To create calendar events for interviews the owner has been invited to.
  • To report status to the owner through their own Telegram chat.

That is the entire use. Data is never used for advertising, profiling, creditworthiness, lending, or any purpose unrelated to the owner's own job search.

Storage and retention

Data is stored only in a local database file on the owner's computer. Extracted text is processed by a language model that runs locally on the same machine; message and calendar content is not sent to any third-party server, cloud AI provider, or analytics service.

Data is kept until the owner deletes the local database, and is removed by deleting that file.

Sharing

No Google user data is sold, rented, transferred or disclosed to any third party. There are no advertisers, no analytics providers, and no sub-processors. The only outbound messages containing job-search results go to the owner's own Telegram chat.

Security

Google credentials (client ID, client secret and refresh token) are stored in a local configuration file on the owner's computer, never in the application's source code, and that file is excluded from version control. Access can be revoked at any time at myaccount.google.com/permissions, which immediately ends the application's access.

Google API Services User Data Policy

Remote Job Radar's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Children

The application is not directed at children and is not made available to any other user.
